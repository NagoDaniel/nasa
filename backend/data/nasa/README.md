# NASA datasets (processed JSON, not DB)

Generated by `scripts/process/` from the raw downloads in `backend/.cache/raw/`
(see `dataset.md`). Each dataset is one file `data/nasa/<dataset>.json`, loaded
once into memory by `app/json_store.py`. Served per unit inside
`GET /api/area/{unit}` and whole via `GET /api/nasa/<dataset>`.

Compact layout: one shared `keys` list (periods) and one value array per unit,
aligned with `keys` (`null` = no data).

```json
{
  "label": "Precipitation (satellite)",
  "source": "NASA GPM IMERG Final Run V07B, monthly (GES DISC)",
  "variable": "precipitation",
  "unit": "mm",
  "aggregation": "sum",
  "period": {"start": "2015-01", "end": "2025-09", "step": "month"},
  "resolution": "0.1° grid (~11 km)",
  "confidence": {"county": "high", "commune": "medium", "note": "…"},
  "status": "complete",
  "missing_periods": [],
  "keys": ["2015-01", "2015-02", "…"],
  "units": {"AB": [49.0, 35.9, "…"], "AB-0012": [51.2, 36.0, "…"]}
}
```

- `units` keys = county `code` (e.g. `AB`) or commune `id` (e.g. `AB-0012`) from the geo layers.
- `aggregation` says how months combine into a year (`sum` for totals, `mean` for states).
- `status` is `sample` while only an AppEEARS sample exists (MOD13Q1 NDVI today).
- Gridded values are area-weighted means of the grid cells overlapping the unit.
- Always fill `source`, `period`, `resolution` and `confidence` — the UI shows them on every chart.

| Dataset | Content | Source |
|---|---|---|
| `imerg_precip` | monthly precipitation, mm | GPM IMERG Final V07B (2015-01 – 2025-09) |
| `gldas_rootmoist`, `gldas_soilmoist_0_10` | soil moisture, mm | GLDAS Noah 2.1 |
| `gldas_et`, `gldas_pet`, `gldas_rain` | ET, potential evaporation, rain, mm/month | GLDAS Noah 2.1 |
| `power_*` | Tmax, Tmean, hot days ≥ 32 °C, frost days, GDD10, precip, RH, soil wetness | NASA POWER daily |
| `firms_fires` | vegetation-fire detections per month | FIRMS VIIRS S-NPP |
| `modis_ndvi` | 16-day mean NDVI (sample: Alba 2024) | MODIS MOD13Q1 via AppEEARS |

Known raw-data issue: `GLDAS_NOAH025_M_201501_AOI.nc4` holds IMERG data (bad
download), so GLDAS 2015-01 is empty (`missing_periods`). The IMERG 2015-01
monthly file is a daily file; that month is rebuilt from the 31 daily files.
